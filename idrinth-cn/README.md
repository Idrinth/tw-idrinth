# Idrinth Thalui: 骑士学者

[![Mod Configuration Tool](https://i.imgur.com/1Vglg7c.png)](https://steamcommunity.com/sharedfiles/filedetails/?id=2927955021)

## 一位堕落学识大师的故事

Idrinth Thalui 曾是一位受人尊敬的高等精灵学识大师，在血腥的吸血鬼战争中迎来了凡人的终结，却以他曾经对抗的生物之姿复活。如今，这位骑士学者在精灵血统与吸血鬼诅咒之间的危险道路上徘徊，在被混沌撕裂的世界中寻找意义。

你将引导他走向救赎，还是拥抱他内心的黑暗？他的命运掌握在你手中。

## 独特招募

Idrinth 可以被那些可能欣赏他双重本性的势力作为领主或英雄招募：
- 帝国（寻求奥术知识）
- 基斯里夫（急需强大盟友）
- 高等精灵（希望召回自己的同胞）
- 木精灵（珍视他与库尔诺斯的联系）
- 吸血鬼伯爵（接纳他新获得的力量）

### 宽松背景模式

在宽松背景模式下，添加了一些代表绝望联盟的不太可能的阵营：
- 布列托尼亚
- 震旦
- 暗精灵
- 纳迦什军团（模组阵营）
- 吸血鬼海岸

## 主要特色

### 神圣恩宠系统

在三位强大的精灵神祇之间平衡你的忠诚，每位神祇都提供独特的方式来统一 Idrinth 分裂的存在：
- **凯恩**：拥抱侵略，增强近战力量和伤害输出
- **阿苏里安**：通过增强防御和魔法抗性寻求平衡
- **库尔诺斯**：引导猎人之道，获得远程优势和机动性

### 礼拜堂系统

基于神圣影响，Idrinth 可以建立礼拜堂，显著影响驻军规模、实力和神恩使用，同时有益于当地经济和发展。

如果未使用所需的模组，外部槽位可能会出现异常行为——除非你正在使用已有外部槽位的阵营，否则技术上不需要该模组。

### 叙事抉择

面对塑造 Idrinth 性格并决定他与神圣关系的关键决定。你将拥抱精灵根源还是屈服于吸血鬼力量？每个选择都会影响你的神圣恩宠并解锁永久加成。

### 神圣神器套装

收集并装备强大的神圣神器来增强 Idrinth 的能力。完成套装可获得补充你所选神圣道路的特殊加成。

### 屠精后果

一个动态特质系统，追踪你与精灵阵营的战斗。你杀死的精灵越多，你在他们中就越臭名昭著、越被鄙视、最终越被憎恨，并带来显著的外交和神圣恩宠后果。

### 奥术多面性

掌握多个魔法学派的法术，反映 Idrinth 的学者背景和吸血鬼转变：
- 吸血鬼学派
- 死亡学派
- 暗影学派

### 自定义战斗阵营

在自定义战斗中使用礼拜堂军队作为独立阵营进行游戏，支持单人和多人模式。

### 野兽 WAAAGH

将军收集一群结盟的动物伙伴，创造一支由受祝福的野兽组成的 Waaagh。

## ALPHA 版本说明

此模组处于**早期 ALPHA** 开发阶段。你可能会遇到：

- 军队中某些按钮可能无法正常工作
- 某些 UI 更改需要一秒钟才能应用
- 平衡性调整正在进行中
- 祈祷系统暂时被随机触发的神圣干预取代

你的反馈对改进至关重要！请报告你遇到的任何问题。

理论上支持自定义纳迦什阵营。然而，支持需要游戏测试——如果你发现错误，请在这里报告，不要打扰其他模组！
