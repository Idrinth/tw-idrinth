# Idrinth Thalui: Turkish / Türkçe

This language pack provides Turkish translations for the [Idrinth Thalui](https://steamcommunity.com/sharedfiles/filedetails/?id=2927955021) mod.

## Requirements

- [Idrinth Thalui: The Knight-Scholar](https://steamcommunity.com/sharedfiles/filedetails/?id=2927955021) (main mod)

## Installation

Subscribe to both this language pack and the main mod. The game will automatically use the translations when your game language is set to Turkish.
