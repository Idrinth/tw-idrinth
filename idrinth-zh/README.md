# 伊德林斯·塔路易：騎士學者

[![模組配置工具](https://i.imgur.com/1Vglg7c.png)](https://steamcommunity.com/sharedfiles/filedetails/?id=2927955021)

## 一位墮落學術大師的故事

曾經是一位受人尊敬的高等精靈學術大師，伊德林斯·塔路易在血腥的吸血鬼戰爭中遭遇了凡人的終結，卻以他曾與之戰鬥的生物之一的形態重新崛起。如今，這位騎士學者在精靈傳承與吸血鬼詛咒之間走著一條危險的道路，在這個被混沌撕裂的世界中尋找意義。

你會引導他走向救贖，還是擁抱他內心的黑暗？他的命運掌握在你手中。

## 獨特招募

伊德林斯可以作為領主或英雄被那些可能欣賞他雙重本性的勢力招募：
- 帝國（追求奧術知識）
- 基斯列夫（急切尋找強大盟友）
- 高等精靈（希望奪回他們的同胞）
- 森林精靈（重視他與庫爾諾斯的連結）
- 吸血鬼伯爵（接受他新獲得的力量）

### 較寬鬆的設定模式

在較寬鬆的設定模式下，會添加一些不太可能的派系，代表絕望的聯盟：
- 布列塔尼亞
- 震旦天朝
- 暗黑精靈
- 納迦什軍團（模組派系）
- 吸血鬼海岸

## 主要特色

### 神聖眷顧系統

在三位強大的精靈神祇之間平衡你的忠誠，每位神祇都提供獨特的方式來統一伊德林斯分裂的存在：
- **凱恩**：以增強的近戰實力和傷害輸出擁抱侵略
- **阿蘇瑞安**：通過提升防禦和魔法抗性尋求平衡
- **庫爾諾斯**：以遠程優勢和機動性引導獵人之道

### 教堂系統

基於神聖影響，伊德林斯可以建立教堂，顯著影響駐軍規模、實力和神恩使用，同時有益於當地經濟和成長。

如果未使用所需的模組，外來建築槽可能會表現異常——除非你扮演的派系已經擁有外來建築槽，否則技術上不需要該模組。

### 敘事困境

面對塑造伊德林斯性格並決定他與神聖關係的關鍵選擇。你會擁抱你的精靈根源還是屈服於吸血鬼力量？每個決定都會影響你的神聖眷顧並解鎖永久加成。

### 神聖神器套裝

收集並裝備強大的神系神器，增強伊德林斯的能力。完成一套可獲得特殊加成，補充你選擇的神聖道路。

### 屠精者後果

一個動態特質系統，追蹤你與精靈派系的戰鬥。你殺死的精靈越多，你在他們同類中就會越出名、越被鄙視，最終被憎恨，帶來重大的外交和神聖眷顧後果。

### 奧術多樣性

精通來自多個魔法學派的法術，反映伊德林斯的學術背景和吸血鬼轉化：
- 吸血鬼學派
- 死亡學派
- 暗影學派

### 自定義戰鬥派系

在自定義戰鬥中將教堂部隊作為獨立派系進行遊玩，支援單人和多人模式。

### 動物WAAAGH

將軍收集一群盟友動物圍繞在身邊，創造出一個由受祝福動物組成的Waaagh。

## ALPHA版本注意事項

此模組處於**早期ALPHA**開發階段。你可能會遇到：

- 軍隊中的某些按鈕可能無法運作
- 某些UI更改需要一秒鐘才能應用
- 平衡調整持續進行中
- 祈禱系統暫時被隨機觸發的神聖干預取代

你的反饋對於改進至關重要！請報告你遇到的任何問題。
